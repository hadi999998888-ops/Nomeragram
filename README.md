# Номер PRO v2
Премиальный мобильный веб-симулятор по мотивам интерфейса из предоставленного видео.

Что добавлено:
- интерфейс в стиле референса: тёмный фон, фиолетовое свечение, карточка редкости, крупный виртуальный номер;
- рабочий генератор;
- после выпадения можно ПРОДАТЬ или ОСТАВИТЬ номер;
- если номер оставлен, следующий обычный ролл блокируется до продажи;
- коллекция сохранённых номеров;
- апгрейд-рулетка: платный ролл, выпавший номер можно обменять только если он дороже текущего;
- ежедневный бонус +1000 ₽ с таймером 24 часа;
- поиск по коллекции;
- анимации и синтезированный звук без внешних аудиофайлов;
- localStorage для сохранения прогресса.

Запуск: открыть index.html или загрузить файлы на GitHub Pages / Cloudflare Pages.

Номера в проекте виртуальные и используются только как игровой симулятор.
